A clean one-column theme for a site dedicated to an employee portal, made for the Dolly Employee Management plugin.

== Description ==

Dolly Portal is a light, accessible one-column theme for a site dedicated to an employee portal.

With the free Dolly Employee Management plugin, the sign-in pages, the employee portal and the workplace display use dedicated templates (in the `dolly` folder) and take the plugin's design, colors, logo and languages from Gestione Dipendenti › Aspetto. Theme pages use the same design.

Without the plugin the theme works as a simple blog and pages theme: posts, pages, archives, search, comments and a primary menu. A dismissible notice in the dashboard recommends the plugin.

Features: one column, custom logo (the Dolly logo by default), custom menu, featured images, threaded comments, wide blocks, translation ready (Italian included), skip link and visible focus styles.

== Installation ==

1. In your admin panel, go to Appearance › Themes and click Add New.
2. Search for Dolly Portal, click Install, then Activate.
3. Optional: install and activate the Dolly Employee Management plugin to turn the site into an employee portal.

== Frequently Asked Questions ==

= Does the theme need the plugin? =

No. The theme works on its own as a blog and pages theme. The plugin adds the employee portal.

= Does the theme hide the site from search engines? =

No. The theme does not change search-engine settings. The Dolly Employee Management plugin keeps its portal pages out of search engines and, with this theme active, the whole portal site (filter `dolly_noindex_site`).
